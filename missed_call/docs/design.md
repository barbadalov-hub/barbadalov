# Дизайн — петля, таймер, арт

## Формат

2D аниме **визуальная новелла**. Почти весь геймплей — переписка в телефоне
(текст, дёшево). Погружение дают ~20–40 полноэкранных **аниме-CG** на
эмоциональных пиках. Реалистично для соло-разработки.

## Каркас (вдохновлено «Исходным кодом»)

```
Кино-пролог (пробуждение)  →  Телефон (игра + таймер)  →  мэтч-кат / петля
```

- Пролог, «воспоминания» и концовки — постановочные сцены.
- Между ними — чат с обратным отсчётом.

## Петля — гибрид

- **Переносится между кругами:** дневник памяти (открытые улики навсегда),
  мгновенное узнавание известного (0 времени), достигнутые якоря, реакции «М.».
- **Сбрасывается:** таймер, доверие «М.», выбор развязки, живые события ночи.
- Формула: помнишь = быстрее; не помнишь = платишь временем. Провал — аванс, не откат.

## Таймер — ~33 минуты

Ночь идёт почти в реальном времени: **03:14 → 03:47**, где 03:47 — неотменяемая
точка («Прочитано 03:47»).

| Параметр | Значение |
|---|---|
| Длина круга | ≈33 мин |
| Новое воспоминание | −2…4 мин |
| Известное (круг 2+) | 0 мин |
| Якорей (чекпоинтов) | 2 — 03:24 и 03:39 |
| Фрагментов всего | 7 |

Якоря спасают от боли 30-минутного провала: новый круг сворачивает пройденное в
короткий монтаж и стартует у якоря, но время всё равно тикает.

**Реализовано в срезе:** `VnController` держит часы ночи (`nightClock`,
`nightProgress`, `isTimeUp`); UI-тикер зовёт `tickNight(dt)`, в шапке идёт
полоса и время 03:14→03:47. На дедлайне `triggerTimeUp()` уводит в death-узел
`death_time` («Время вышло»), а `loopFromDeath` сбрасывает ночь. Длина ночи —
`VnController.nightSeconds` (сейчас 150 c для среза; в полной игре ~реальное
время). Таймер стоит на death-сценах и на `slice_end`.

## 7 фрагментов-воспоминаний

Зеркало (ты) · мокрая одежда (выходил ночью) · чужой телефон + фото двора ·
три пропущенных · ссора · двор/лёд/шаг · голосовое. Собрать все — путь к
истинной концовке «Голосовое».

**Реализовано в срезе:** список в `engine/fragments.dart`; экран-хаб памяти
(`memory_hub`, флаг `isMemoryHub`) даёт «вспоминать». Первое воспоминание стоит
`cost` секунд ночи (`VnController.recall` двигает часы вперёд); уже известное
(флаг `fragment:<id>`, переносится через death-петлю) — **бесплатно и мгновенно**.
Это и есть двигатель гибрида: с каждым кругом за тот же таймер доходишь дальше.
Таймер в хабе на паузе — платишь только ценой воспоминаний.

## Арт-дирекшн

- **Атмосфера как система:** палитра сдвигается под эмоцию (см. `ui/mood_palette.dart`).
- **Три голоса типографики:** интерфейс (гротеск) · душа (антиква-курсив,
  воспоминания/финалы) · правда (моноширинный, таймстампы/«прочитано»).
- **Свет и звук диегетичны:** луна, лампа, экран; звонок, гул комнаты. Музыка —
  только на концовках.
- **Экономия:** ~20–40 CG + статичные фоны + чат. Начать с 5 CG пролога.

## Движок (этот прототип)

Сцены — data-driven граф узлов (`engine/script_act1.dart`) — единый источник
правды, как `kTodaySections` в LifeOS. `VnController` (ChangeNotifier) ведёт
текущий узел; `VnScreen` рендерит CG-плейсхолдер + диалог + выборы; палитра
меняется по `Mood`. Плагин-фри, ноль сторонних зависимостей.
